# Источники данных для приватной версии

Проверено 19 сентября 2026 года.

## PhoneBlock

- Бесплатный community-сервис без рекламы, но production API требует токен
  учётной записи. Анонимный запрос к `/api/check` возвращает HTTP 401.
- Входящий номер отправляется как SHA-1 от E.164, поэтому сам номер не уходит
  на сервер при проверке звонка.
- `/check` возвращает число голосов и категорию спама. Источник не предназначен
  для поиска имени обычного человека или компании.
- API также поддерживает полный и инкрементальный blocklist. Для первой версии
  используется on-demand проверка; загрузку списка можно добавить после
  проверки покрытия по странам пользователя.
- Документация: <https://phoneblock.net/phoneblock/api>
- Руководство интеграции: <https://github.com/haumacher/phoneblock/blob/master/INTEGRATIONS.md>

## IPQualityScore

- Требует бесплатную учётную запись и API-ключ. Публичная страница обещает
  бесплатный план без карты, но не фиксирует гарантированный месячный лимит
  именно phone lookup; фактический остаток нужно смотреть в кабинете.
- Возвращает fraud score, признаки `spammer`/`risky`, тип линии и иногда имя.
  Сам IPQS указывает, что reverse-name лучше покрывает США и Канаду и ограничен
  в Европе и Азии.
- API работает в реальном времени; в приложении результаты с именем хранятся
  30 дней, риск и отсутствие результата — 24 часа.
- Документация: <https://www.ipqualityscore.com/documentation/phone-number-validation-api/overview>
- Бесплатная регистрация: <https://www.ipqualityscore.com/create-account/phone-validation>

## tellows

- Требует платный API-ключ. Приватный ключ стоит €19.95 на два года, то есть
  примерно €0.83 в месяц, и укладывается в заданный бюджет.
- Даёт score, наиболее частое имя/категорию и ежедневно обновляемые scorelists.
- Приватная лицензия не подходит для будущей платной публичной версии. Перед
  публикацией потребуется коммерческая лицензия и повторная проверка стран.
- Страница приватного ключа: <https://shop.tellows.de/en/tellows-api-key.html>

## Использование tellows

При сохранённом приватном ключе tellows участвует в параллельной проверке как
третий независимый источник. Его score, наиболее частое имя и категория номера
сохраняются отдельно от ответов PhoneBlock и IPQS. На первом этапе это только
личная debug-сборка с приватным ключом и ручной выборкой из 50 неизвестных
номеров.

Перед включением tellows в публичную или платную версию нужно получить
коммерческую лицензию, проверить разрешённые страны и лимиты запросов, а также
сравнить качество и стоимость с уже подключёнными источниками. Результаты
tellows должны попадать в общий `LookupEvidence` и не могут перезаписывать
имя из книги контактов, разрешения или блокировки пользователя.

## Принятая политика приложения

- Внешние источники только предупреждают. Автоматическая блокировка возможна
  лишь для личного правила `BLOCK`.
- Разрешения и блокировки имеют приоритет над внешним кешем. Имя из книги
  контактов имеет приоритет; без контакта заголовок берётся из IPQS, затем
  tellows. Разные внешние имена показываются вместе с источниками.
- Приложение не перебирает журнал звонков и не расходует квоту фоновыми
  повторными запросами.
- Все источники с сохранёнными ключами проверяются параллельно. У каждого
  результата свой локальный срок кэширования: имя до 30 дней, репутация и
  отсутствие данных до 24 часов. Ошибки сети и квоты не кэшируются.
